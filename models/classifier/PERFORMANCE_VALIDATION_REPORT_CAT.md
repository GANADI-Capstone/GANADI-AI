### 3. 강·약점 요약

✅ **강점**
- **Recall 이 전반적으로 높음** (5개 중 4개 질환에서 0.83 이상)
  → "이상 케이스를 놓치지 않는다" 는 스크리닝 도구로서의 본질에 부합.
- 비궤양성각막염·안검염은 표본 수가 적음에도 F1 0.86+ 로 강함.

⚠️ **약점 (개선 우선순위)**
1. **결막염** — Acc 72%, Recall 70% 로 5개 질환 중 최저.
   - 정상 vs 결막염의 충혈/분비물 차이가 사진 환경(조명·각도)에 매우 민감.
   - 데이터 증강 시 색조(saturation/hue) 변동을 더 넣고, 어두운 사진에 더 강건한 학습 권장.
2. **각막궤양** — Acc 79.8% 로 그 다음. 궤양 크기 다양성이 커서 일관된 패턴 학습이 어려움.

## 🧪 검증 메서드

1. `models/classifier/comprehensive_eval.py --species cat` 실행
2. EfficientNet-B3, `cat_best.pth` 로드 (MPS)
3. `eye_data/VL/고양이/안구/일반` 만 사용 (학습에 쓰지 않은 검증 폴드)
4. 질환별로 sklearn `accuracy / precision / recall / f1 / confusion_matrix` 계산
5. JSON + CSV 로 결과 저장 (`models/classifier/eval_results/`)

데이터 누수(Data Leakage) 검사는 학습 시점의 split 기준으로 동일한
폴더 격리 정책을 사용하므로, 강아지 보고서와 동일하게 누수 가능성은 없음.
